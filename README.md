# Генерация сувениров — Пидан

Рабочий каталог макетов для ЧПУ и лазера, плюс локальная галерея/техлендинг. На изделиях высота всегда **1333 м** (не 1332).

## Быстрый старт

```bash
pip install -r requirements.txt
python scripts/build_gallery.py
python scripts/gallery_server.py
```

Лендинг: http://127.0.0.1:8765/

Фото-рамка 10×15 (лазер SVG, превью, инструкция):

```bash
python -m scripts.photo_frame
```

Результат: `images/рамки/10кс15/` (`лазер/`, `превью/`, `инструкция/`). Правила: `.cursor/rules/photo-frame-laser.mdc`.

## Карта папок

| Путь | Что здесь |
|---|---|
| `images/медали/` | Heightmap медалей; готовое к станку — в `обработанные/` |
| `images/чпу/` | Кулоны ЧПУ, `финальные/` — отобранное для станка |
| `images/лазер-магниты/` | Лазерные магниты (серии «В даль», «Насыпь», «Тринога велик») |
| `images/лазер-кулоны/` | Лазерные кулоны и брелки |
| `images/мотивация/` | Лазерные мотивашки, надписи, векторы, серия восхождений |
| `images/витрины/` | Доска-витрина, концепты, плитки 200×300 |
| `images/подножье-пидана/` | Ко-бренд базы «подножье ПИДАНА» (`лазер/`, `макеты/`) |
| `images/сафари-парк/` | Сувениры сафари-парка (`лазер/`, `чпу/`, `макеты/`, `референсы/`) |
| `images/3д-печать-пидан/` | Настольный Пидан, снимки Google Earth |
| `images/рамки/` | Фоторамки под лазер; сейчас `10x15/` |
| `images/магниты/` | Резерв под ЧПУ-магниты (пока пусто) |
| `assets/` | Брендовые референсы: логотип базы, след тигра |
| `станки/` | Проекты Carveco (`.crv3d`), в git не входят |
| `_inbox/` | Дампы Cursor/ChatGPT и безымянные исходники; **не в галерее** |

Новые генерации сразу класть в нужную папку `images/…`, не в корень репозитория. После изменений обновляйте данные лендинга.

## Правила генерации

Роутинг пайплайнов — `.cursor/rules/generation-workflow.mdc`. После новых файлов в проекте:

```bash
python scripts/build_gallery.py
```
